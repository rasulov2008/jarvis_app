# Джарвис · HEMIS (Telegram Mini App)

Расписание, НБ, экзамены, оценки, а в разделе «Ещё» — задания, ресурсы, предметы, контракт и настройки уведомлений.
Данные берёт у вашего бота; в репозитории нет токенов и паролей.

- Предпросмотр без бота: добавьте `?demo` к адресу страницы.
- Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
- В Render: `WEBAPP_URL` = адрес страницы (со слешем на конце).
- Файлы: `index.html` (каркас), `style.css` (палитра и компоненты), `app.js` (логика, кэш, демо-данные), `config.js`.
- Кэш на устройстве: расписание 10 мин, НБ 30 мин, экзамены 3 ч и т. д.; кнопка с временем в шапке обновляет экран.
