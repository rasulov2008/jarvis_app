# Джарвис · HEMIS (Telegram Mini App)

Статичное приложение: расписание, НБ, экзамены, оценки, а в разделе «Ещё» — задания, ресурсы, предметы, контракт и настройки уведомлений.
Данные берёт у вашего бота; в репозитории нет ни токенов, ни паролей.

- Предпросмотр без бота: откройте страницу с `?demo` в конце адреса.
- Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
- В Render добавьте `WEBAPP_URL` с адресом вида `https://ВАШ-НИК.github.io/jarvis-app/` (со слешем на конце).
- Кэш: данные хранятся на устройстве (localStorage) и считаются свежими от 10 минут (расписание) до 6 часов (контракт, ресурсы).
  Пока они свежие, приложение не обращается к боту. Кнопка ⟳ в шапке принудительно обновляет экран.
