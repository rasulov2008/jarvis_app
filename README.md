# Jarvis · Учёба Mini App (v3)

Статический Telegram Mini App для Jarvis / HEMIS (GitHub Pages).
- Главный экран «Главное»: текущая/следующая пара в реальном времени, срочные дедлайны, риски НБ, ближайший экзамен и GPA.
- Мгновенный запуск: ранний `Telegram.WebApp.ready()`, `preconnect`, параллельный inline prefetch, Service Worker (`sw.js`) и stale-while-revalidate кэш.
