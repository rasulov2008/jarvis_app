# Джарвис · HEMIS (Telegram Mini App)

Статичное приложение: расписание, НБ, экзамены, оценки. Данные берёт у вашего бота, в репозитории нет ни токенов, ни паролей.

Предпросмотр без бота: откройте страницу с `?demo` в конце адреса.

Публикация на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
Потом в Render добавьте переменную `WEBAPP_URL` с адресом вида `https://ВАШ-НИК.github.io/jarvis-app/`.
