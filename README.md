# Джарвис · HEMIS & Финансы (Telegram Mini App 2.0)

Обновлённый веб-интерфейс для Telegram Mini App бота Джарвис:
- **📅 Расписание**: сетка дней недели, прогресс текущей пары в реальном времени и выгрузка расписания с экзаменами в календарь `.ics` (`/api/calendar.ics`).
- **📊 НБ**: контроль лимита 25% аудиторных часов и история пропусков по датам.
- **🎓 Оценки и 🎯 Цели на сессию**: текущая успеваемость, GPA и интерактивный калькулятор целевых баллов на 2-ON / Final (`/api/grade_targets`).
- **💸 Финансы**: балансы по счетам (карта, наличные), быстрая запись расходов/доходов/переводов с поддержкой валют (`POST /api/money/tx`), предиктивный Burn-Rate, безопасный дневной лимит, структура расходов по категориям, трекер долгов и регулярных подписок (`/api/money/overview`).
- **⊞ Ещё**: экзамены (1-ON, 2-ON, текущий контроль, сессия), задания с отправкой файлов в чат, учебные ресурсы, предметы, контракт с записью платежа и настройки уведомлений.

## Запуск и публикация
- Предпросмотр без бота: откройте `index.html?demo`.
- Публикация на GitHub Pages: `Settings → Pages → Deploy from a branch → main / (root)`.
